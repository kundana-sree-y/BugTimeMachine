# 🐞 BugTimeMachine

### An Interactive Python Debugging and Learning Platform

BugTimeMachine is a Python-based learning platform designed to help beginners understand how code works through visual explanations, step-by-step execution, and debugging support.

Instead of only showing the final output, the platform aims to make program execution easier to understand by helping learners observe how code behaves at each step.

## ✨ Features

- **Step-by-Step Code Execution:** Understand program execution one step at a time.
- **Code Debugging:** Identify and understand errors in Python code.
- **Variable Tracking:** Observe variable values as the program executes.
- **Output Visualization:** View program output in an organized interface.
- **Animated Algorithm Learning:** Explore algorithms such as Bubble Sort through visual animations.
- **Beginner-Friendly Interface:** Learn programming concepts through an interactive web interface.
- **Code Learning Support:** Practice Python and improve your understanding of program flow.

## 🚀 Getting Started

### Prerequisites

- Python installed on your computer
- pip, Python's package installer

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/kundana-sree-y/BugTimeMachine.git
   ```

2. Open the project folder:

   ```bash
   cd BugTimeMachine
   ```

3. Install Flask:

   ```bash
   python -m pip install flask
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local address shown in the terminal, usually:

   `http://127.0.0.1:5000`
